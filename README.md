# 🎶 Want to use your own music?
You can customize the song and beatmap in the VisualBeatEditor folder to create your own rhythm experience!

We use .json to store the song scores and put them in BeatBook

📌 Don’t forget:

Update the BPM in the Conductor script to match your track

Make sure your scene name matches the beatmap name for proper loading!
